# 세계 음식대백과 FRESH V1.1

새 저장소 GitHub Pages 루트에 이 폴더의 파일 전체를 올리세요.

- 독립 HTML/JS 구현. 기존 카드·설명·검색결과는 코드에 포함하지 않았습니다.
- 실제 추출된 대표 음식 목록: 27개국, 205개 이름. **101개국 전체 목록 확보는 미완료**입니다.
- 모든 항목은 검색 전 흰색에서 출발합니다.
- Wikipedia 공개 API를 이용해 후보를 검색하며, 검색 성공을 정확성 검증으로 오인하지 않습니다.
- 자동검색은 순차 실행됩니다. 브라우저 중단, CORS, API 제한 시 실패할 수 있습니다.
- 데이터는 별도 키로 저장되며, 결과 초기화 및 JSON 백업을 제공합니다.
- 외부 검색 후보의 설명/사진은 검증되지 않았습니다. 정확한 한글 발음명 및 영어·현지어 별칭의 전체 검증은 후속 작업입니다.
