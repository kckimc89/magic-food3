# 세계 음식대백과 — 독립 설치 검증판 FRESH V1.0

이 패키지는 V8.229.0 전체 앱을 **새 GitHub 저장소/새 배포 주소에서 독립 설치**하기 위한 기준판입니다.

## 설치
1. GitHub에 새 공개 저장소를 만들고 압축을 푼 **파일 전체**를 저장소 루트에 올립니다.
2. Settings → Pages → Deploy from a branch → main / (root) → Save.
3. 발급된 Pages 주소로 접속합니다. 기존 앱과 **다른 URL origin**을 사용하면 저장 데이터가 분리됩니다.
4. Safari에서 홈 화면에 추가할 수 있습니다.

## 중요 제한
- 이 버전은 **완전한 신규 검색엔진을 구현한 판이 아닙니다.** 기존 V8.229.0 엔진을 별도 저장소에 설치하는 분리 검증판입니다.
- 전체 101개국 음식별 이름·별칭 검증, 전수 자동검색, 정확도 99% 검증은 **미완료**입니다.
- 기존 앱과 같은 도메인의 경로만 다르게 배포하면 localStorage가 공유될 수 있습니다. 별도 도메인/서브도메인을 사용하세요.
- GitHub Pages 자체는 외부 API의 CORS·접속 제한을 해결하지 않습니다.
