# 세계 음식대백과 FRESH V1.9 — 안전한 별칭·오검색 점검

- 27개국 205개 음식과 기존 IndexedDB 저장소를 유지합니다.
- V1.8 품질 보고서의 명백한 오검색 사례를 탐지하고, 영어/현지어 별칭을 검색 질의에 연결합니다.
- 진단은 읽기 전용이며 기존 초록색 카드에 일괄 변경을 가하지 않습니다.
- 위험 보라색 후보만 선택적으로 정밀 재검색합니다. 결과가 없으면 기존 후보를 보존합니다. 새 결과는 검토 후보로 남깁니다.
- 설명이 정확하다면 사진 없이도 사용자가 카드 완료할 수 있습니다.
- 배포 전에 결과 백업을 권장합니다. 기존 저장소의 원본 데이터는 삭제하지 않습니다.
- 검색 결과는 Wikipedia API 가용성에 좌우됩니다.
